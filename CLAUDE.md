# Cospire LMS Repository Entry Point

Read `CONTEXT.md` first and follow its mandatory context protocol at the start and
end of every task.

Then read the full operating manual at `../CLAUDE.md`. The parent manual defines
how this repository is built; the signed agreement in `../Context/` defines what
is delivered. When they conflict, the agreement wins.

Before handing off, update `CONTEXT.md` with completed work, active work, pending
work, blockers, decisions, files changed, and verification results. Never place
secrets or client/student data in the context file.
